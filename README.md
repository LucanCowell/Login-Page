# Login-Page
This is a testing repository to create a functional login system

This login system works through an array and does not use SQL or any other databse-type language. To login to this page, the user must first use the sign up page which currently has requirements on the username length but in future will also ensure that the username does not contain special characters while also ensuring that the password is of the correct length.

When the passwords doesn't match, the account will not be created.
